# USS files

Under **Unix Files (USS)**, click **Add USS Path** (folder icon) and enter a directory, for example `/u/user01` or `/var/log`.

| Action | How |
|---|---|
| Browse | Expand folders. Each entry shows its permissions and size. |
| Open / edit / save | Click a file, edit it, press ++ctrl+s++ |
| New file | Right-click a folder → **Create USS File** |
| New folder | Right-click a folder → **Create USS Directory** |
| Upload | Right-click a folder → **Upload Local File to Member / USS** |
| Delete | Right-click → **Delete**. Folders are deleted with everything in them. |

Files are transferred as **text**, and z/OSMF converts them to and from EBCDIC automatically according to the file tag.
